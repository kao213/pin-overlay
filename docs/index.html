pin-overlay の使い方

好きな画像や文字を、ゲーム画面の上にずっと表示しておけるツールです。インターネット接続は要りません。

完成するとこう見えます（背景はゲーム画面のイメージ）。表示中も、下のゲームはふつうに操作できます。

ゲームの画面モードは「ボーダーレス」（または「ウィンドウ」）にしてください。
「フルスクリーン」のままだと、ゲームの上に表示されません。

はじめに 1 回だけやること

1ダウンロードする

下のリンクを開き、「Assets」の中の pin-overlay.exe をクリックします。

https://github.com/kao213/pin-overlay/releases/latest
ブラウザに「一般的にダウンロードされていません」などの警告が出たら、
「…」や「∧」のメニューから 「保存」→「保持する」 を選んでください。

2専用のフォルダに移す

デスクトップなどに pin-overlay という名前のフォルダを作り、ダウンロードした pin-overlay.exe をその中に移します。

起動すると、同じ場所に画像用のフォルダと設定ファイルが作られるためです。

「Program Files」の中には置かないでください。設定が保存されません。

3ダブルクリックして起動する

初めて起動するとき、青い画面で 「Windows によって PC が保護されました」 と出ることがあります。

「詳細情報」 をクリック → 下に出てくる 「実行」 を押してください。

この設定画面が開けば OK です。

表示したい画像を入れる

4「画像フォルダを開く」を押す

設定画面の右上にある 画像フォルダを開く を押すと、images フォルダが開きます。

5images の中にフォルダを作り、画像を入れる

images の中に フォルダを作って、その中に画像を入れます。フォルダの名前は自由です。

pin-overlay\ ├─ pin-overlay.exe └─ images\ ├─ 収集アイテム\ ← フォルダ 1 つ ＝ 設定画面のタブ 1 つ │ ├─ 時計.png │ ├─ 指輪.png │ └─ … └─ 目的地\ └─ A地点.png
  • 使える画像：PNG・JPEG・BMP・GIF・WebP
  • images の中に直接置いた画像は表示されません（必ずフォルダに入れる）
  • 画像のファイル名が、設定画面での名前になります

6「⟳ 再読み込み」を押す

設定画面に戻って ⟳ 再読み込み を押すと、作ったフォルダがタブになって並びます。

あとで画像を足したり消したりしたときも、このボタンを押します。

画面に表示する

7表示したい画像にチェックを付ける

画像をクリックするとチェックが付き、青い枠になります。タブの横の数字は、チェックした枚数です。

8表示された画像を、好きな場所までドラッグする

チェックした画像が、黄色い点線の枠に囲まれて画面に出ます。タブ（フォルダ）ごとに 1 つのかたまりです。

かたまりをドラッグして、ゲーム中に見やすい位置へ動かします。

9「透過して表示 ▶」を押す

設定画面の右下の 透過して表示 ▶ を押すと、設定画面が消えて黄色い枠もなくなります。

この状態では、画像の上をクリックしても下のゲームにそのまま届きます。ゲームを始めて大丈夫です。

ボタンが押せないときは、画像に 1 つもチェックが付いていません。

設定画面に戻りたいとき

表示する画像を変えたい・位置を動かしたいときは、次のどれかで設定画面に戻れます。

① ⚙ を押す かたまりの右上にある小さな ⚙ を押します。
② タスクトレイから 画面右下のアイコンを右クリック →「設定画面を開く」。
設定画面を開く
終了

アイコンが見当たらないときは、右下の「∧」の中に隠れています。

③ もう一度起動する ①も②も見つからないときは、pin-overlay.exe をもう一度ダブルクリックしてください。設定画面が開きます。

終わるとき

設定画面の右上の × で閉じるか、タスクトレイのアイコンを右クリック →「終了」を押します。

チェック・位置・大きさは自動で保存され、次に起動したときも同じ状態で表示されます。

もっと使う

文字を表示する

「テキスト」タブに書いた文字が、そのまま画面に表示されます（黒い縁取り付き）。

文字を選んでから、上のボタンで色・太字・大きさなどを変えられます。表示したくないときは文字を消してください。

大きさ・並び方を変える（タブごと）

拡大率画像の大きさを % で変えます。100 が元の大きさです。
最大サイズ画像がこれより大きくならないようにします。大きすぎる画像を小さくしたいときに。
折り返し幅横に並べた画像がこの幅を超えると、次の行に送ります。0 なら 1 列にずっと並べます。
すべて表示／すべて非表示そのタブの画像のチェックを、まとめて付けたり外したりします。
不透明度（画面の下）すべてのかたまりを、うっすら透けさせます。

タブの名前の部分をドラッグすると、タブの並び順を変えられます。

うまくいかないとき

ゲームの上に表示されないゲームの画面モードを「ボーダーレス」か「ウィンドウ」にしてください。
タブが出てこないimages の中にフォルダを作って画像を入れたか確認し、⟳ 再読み込み を押してください。
画像に「読み込めません」と出るWebP 画像の場合は、Microsoft Store の「WebP 画像拡張機能」を入れてください。それ以外は、画像を PNG で保存し直してください。
「設定を保存できませんでした」と出るpin-overlay.exe を、デスクトップやドキュメントの中のフォルダへ移してください。
設定画面に戻れないpin-overlay.exe をもう一度ダブルクリックしてください。

ご注意

  • このツールは画面の一番手前に画像を出すだけで、ゲームの中身を読んだり操作を横取りしたりはしません。ただし、チート対策ソフト（BattlEye など）に問題にされないことは保証できません。自己責任でお使いください。
  • このツールはゲーム会社（Battlestate Games）の公認ツールではありません。
  • ゲームの画像は付いていません。各自で用意してください。ゲームの画像を他の人に配ることは、ゲームの利用規約で禁止されています。
