# pin-overlay 設計書

> 設計中のドラフトです。決まったことを随時追記します。

## 1. 目的

画面の最前面に、好きな画像やテキストをオーバーレイ表示するオフラインツール。

ベースの用途は **Escape from Tarkov の Collector タスク**。必要なアイテムをチェックボックスで選び、レイド中に画面へ表示しておく。
ただし作りは汎用にして、フォルダに画像を置けばどんな用途にも使えるようにする。

## 2. 技術スタック

| 項目 | 内容 |
|---|---|
| 言語・UI | C# + WPF |
| ランタイム | .NET 10 |
| 配布 | 実行環境を同梱した単一の exe（自己完結型）。インストール不要で、ダブルクリックで起動する |
| 対応 OS | Windows |

## 3. 画面とモード

画面は「設定画面」と「透過表示」の 2 つ。

```
[設定画面（編集モード）] ──「透過して表示」ボタン──▶ [透過表示]
          ▲                                          │
          └── ピンの ⚙ をクリック ／ トレイアイコンの「設定画面を開く」 ──┘
```

### 3.1 設定画面（編集モード）

- 画像フォルダ内のサブフォルダがタブとして並び、最後に「テキスト」タブがある
- タブの中身をチェックボックスで表示／非表示にする
- 画面上のかたまり（ピン）には枠が出て、ドラッグで移動できる
- 画像のカードは、チェックボックス以外の場所を押してもチェックが切り替わる
- 「画像フォルダを開く」ボタンで、`images` フォルダをエクスプローラーで開ける（フォルダのパスは画面に出さない）
- 画像のタブが 1 つも無いときは、画面上部（ボタンの左）に使い方の案内を出す。タブの上に重ねるとテキストタブの操作部を隠すため
- 設定画面を×で閉じると、アプリを終了する（トレイメニューの「終了」と同じ）

### 3.2 透過表示

- かたまりは枠なしで表示され、クリックは下のウィンドウ（ゲームなど）に届く
- かたまりの右上に小さな ⚙ を置き、そこだけクリックを受け付ける。押すと設定画面に戻る
  - ⚙ は普段から表示しておく
- タスクトレイに常駐し、右クリックメニューから「設定画面を開く」「終了」を選べる（「ピンを一時的に隠す」は入れない）
- ホットキーは使わない（覚えにくいため）
- 透過中の右クリックを横取りする仕組み（マウスの動きを常に監視する方式）は使わない。右クリックが下のゲームにも届いてしまううえ、チート対策ソフトに検出されるおそれがあるため

## 4. 画像フォルダとタブ

### 4.1 フォルダ構成

exe と同じ場所の `images` フォルダに固定する（変更はできない）。

```
pin-overlay.exe
images/
├─ Xxx/
│  ├─ Aaa.png
│  └─ Bbb.png
└─ Yyy/
   ├─ Ccc.png
   └─ Ddd.png
```

- `images` 直下のサブフォルダ 1 つが、タブ 1 つになる
- タブ名はフォルダ名
- `images` 直下に置かれた画像と、孫フォルダ（`images/Xxx/Zzz/` など）の中身は表示しない
- 画像の追加・削除は、使う人がフォルダに直接ファイルを置いて行う
- 「再読み込み」ボタンで、フォルダの変更を反映する

### 4.2 タブの並び順

- タブはドラッグ＆ドロップで並べ替えられる
- 並び順は保存し、次に起動したときも同じ順で表示する
- 新しく追加されたフォルダは、末尾（テキストタブの手前）に追加する
- テキストタブは常に最後に置く

### 4.3 チェックボックス

- 画像ごとにチェックボックスがあり、**チェック＝表示する**
- 想定している使い方：まだ必要なアイテムにチェックを付け、手に入れたら外す
- 別のタブに切り替えてもチェックは残る
- チェック状態は保存し、次に起動したときも復元する

## 5. 画像の表示

### 5.1 かたまり（ピン）

- タブ（フォルダ）ごとに 1 つのかたまりとして表示する
- かたまりは編集モードでドラッグし、好きな位置に置ける。位置は保存する
- かたまりの中では、チェックした画像を横に並べる。タブごとの「折り返し幅」（px）を超える場合は次の行へ送る。折り返し幅が 0（既定）なら横 1 列のまま折り返さない
  - 画像 1 枚だけで折り返し幅を超える場合は、その画像だけで 1 行にし、かたまりの幅をその画像に合わせて広げる（画像が切れないように）
  - 折り返し幅を設定したタブは、かたまりの幅を画像の量によらず折り返し幅に固定する。編集モードの枠がその幅になるので、画面上で幅を確かめられる（⚙ も枠の右上に付く）
- ファイル名は表示しない（画像だけを並べる）

### 5.2 大きさ

タブごとに「拡大率」と「最大サイズ」を設定する（「折り返し幅」も同じ場所で設定する。5.1 参照）。

- **拡大率**：%で指定する
- **最大サイズ**：選択肢（例：64／128／256px）から選ぶか、入力欄に数値を自由に入れる

計算の手順：

1. 元の画像に拡大率をかける
2. 長いほうの辺が最大サイズを超える場合は、縦横比を保ったまま最大サイズに収まるよう縮小する。超えない場合はそのまま

例：拡大率 150%、最大サイズ 128px

| 元の画像 | ① 拡大率を適用 | ② 最大サイズに収める（最終サイズ） |
|---|---|---|
| 256×256 | 384×384 | 128×128 |
| 256×128 | 384×192 | 128×64 |
| 100×100 | 150×150 | 128×128 |
| 64×64 | 96×96 | 96×96 |

## 6. テキストタブ

- テキストタブには、リッチテキストエディタを 1 つだけ置く（チェックボックスはない）
- エディタに書いた内容が、そのまま 1 つのかたまりとして表示される。表示したくない部分は消す
- エディタの上に小さなツールバーを置き、次の項目を設定できるようにする
  - フォント
  - フォントサイズ
  - 文字色
  - 太字・斜体
  - 揃え方（左／中央／右。行ごとに設定できる）
- 書式は文字単位で変えられる（1 行の中で一部だけ色を変える、など）
- 実装には WPF 標準の `RichTextBox` を使う。ツールバーは自作する
- 書式付きの内容は、`settings.json` に文字列として保存する

### 6.1 縁取り

- 透過表示のときは、文字に縁取りを付ける（ゲーム画面の上でも読みやすくするため）
- `RichTextBox` に縁取りの機能はないので、表示時に自前で描く
- 縁取りの色は全体で 1 色（初期値は黒）

## 7. 対応する画像形式

| 形式 | 拡張子 | 補足 |
|---|---|---|
| PNG | `.png` | 透過に対応 |
| JPEG | `.jpg` `.jpeg` | |
| BMP | `.bmp` | |
| GIF | `.gif` | アニメーション GIF は最初の 1 コマだけ表示する |
| WebP | `.webp` | |

これ以外の拡張子のファイルは無視する。

- WebP は、Windows に「WebP 画像拡張機能」が入っていないと読み込めない
- 読み込めない画像は、設定画面のカードに「読み込めません」と表示し、オーバーレイには出さない

## 8. マルチモニター・高 DPI

- **画面外のかたまりを戻す**：起動時に、どのモニターにも収まっていないかたまり（外したモニター上にあったものなど）を検出し、メインモニターの中に移動する
- **ピクセル数どおりに表示する**：Windows の表示スケール（125%、150% など）に関係なく、画像の大きさ（拡大率・最大サイズの計算結果）は画面上の実ピクセル数として扱う。最大サイズ 128px なら、どの環境でも 128 ピクセルで表示する
- **モニターごとの表示スケールに対応する**：表示スケールが違うモニターの間でかたまりを動かしても、大きさが変わったりぼやけたりしないようにする（Per-Monitor DPI Aware V2）

## 9. 不透明度

- すべてのかたまり（画像・テキスト）に共通の不透明度を 1 つだけ設定する

## 10. 保存

- 設定はすべて exe と同じ場所の `settings.json` にまとめて保存する
- 変更のたびに少し待ってからまとめて保存する。透過表示に切り替えるときと、終了するときにも保存する
- `settings.json` が壊れていた場合は `settings.json.broken` に退避し、既定の設定で起動する
- `images` フォルダと同じく exe の横に置くので、フォルダごとコピーすれば別の PC でも同じ状態で使える
- exe は `Program Files` のような書き込みに管理者権限が必要な場所ではなく、デスクトップやドキュメントなどに置いてもらう（README に書く）

保存する内容：

- タブの並び順
- 画像ごとのチェック状態
- タブごとの拡大率・最大サイズ・かたまりの位置
- テキストタブの内容（書式付き）・かたまりの位置
- 縁取りの色
- 不透明度

## 11. 注意事項（README にも書く）

- **ゲームの画面モードは「ボーダーレス」にする**。排他的フルスクリーンの上には表示できない
- **チート対策ソフト（BattlEye など）について**：最前面にウィンドウを表示するだけで、ゲームのメモリを読んだり、入力を横取りしたりはしない。ただし、問題にならないことを保証はできないので、自己責任で使ってもらう
- **ゲームの画像はリポジトリに含めない**。著作権があるため、使う人が自分で `images` フォルダに入れる
